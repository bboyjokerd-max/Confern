Confern 使用說明
================

怎麼安裝（兩種都可以，裝了就用第一種）
----------
  ① 安裝版：雙擊 Confern-Setup-0.1.0.exe → 下一步、下一步、完成。
     安裝到 %LOCALAPPDATA%\Programs\Confern（不需要管理員權限），會建立開始功能表捷徑，
     桌面捷徑可勾選，並在「應用程式與功能」留下一筆可以正常解除安裝的記錄。
     如果這台電腦沒有 .NET 8 桌面執行階段，安裝程式會**先問你**要不要自動下載安裝，
     選「否」就結束安裝（不會留下一個打不開的半成品）。
     升級＝直接跑新版的安裝檔，會覆蓋舊版，不會裝兩份。
     不想看精靈可以用：Confern-Setup-0.1.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

  ② 免安裝版：整個 app\ 資料夾複製到任何地方，直接跑裡面的 Confern.exe。
     這樣就沒有捷徑與解除安裝記錄，改版時自己覆蓋資料夾。
     （需要 .NET 8 桌面執行階段；沒有裝的話程式會開不起來，不會有提示。）

這是什麼
--------
拖一個檔案到桌面空白處、按住觸發鍵（預設是空白鍵），畫面中央會出現一圈扇形，選一個就開始轉檔。
輸出預設放在來源檔旁邊，而且**永遠不會覆蓋**既有檔案（重名會自動編號）。

怎麼開始
--------
1. 啟動 Confern（開始功能表捷徑，或 app\Confern.exe）。
   系統匣（右下角時間旁邊）會出現一個圖示，沒有錯誤視窗就是好的。
2. 拖一個圖檔到桌面空白處 → 按住觸發鍵（預設空白鍵）→ 選扇形。
   ．拖曳途中按 Shift：切到工具輪盤（旋轉／清理／壓縮／裁切／讀 QR／去背）。
   ．拖進 PDF 時會多出「合併 PDF」那一格。

系統匣圖示
----------
  右鍵：開啟設定／暫停轉換／結束
  雙擊：開啟設定頁

設定
----
  設定頁面九列（預設輸出位置、JPG 品質、觸發鍵、語言、配色、開機自動啟動…）。
  觸發鍵可選：空白鍵／Tab／Alt／CapsLock／Escape／Shift，或按「按下新鍵」自己按一個
  （修飾鍵也可以，只擋 Win）。Alt／Ctrl／Shift 在檔案總管裡本來就是別的手勢——Alt 單按會讓
  視窗進選單模式、Ctrl 拖曳是複製、Shift 拖曳是移動——設定頁會把這件事寫在那一列旁邊。
  想用寫檔的方式換：把設定檔（路徑見下）裡的 TriggerKey 寫成 "Alt" 就是 Alt 觸發。
  語言 9 項（跟隨系統 ＋ 8 種語言）、配色 6 套。
  設定檔位置：%LOCALAPPDATA%\Confern\settings.json（改壞了刪掉就會回到預設）。

命令列（托盤程式開著也能用）
--------------------------
  Confern.exe formats                      # 這台能讀什麼、能寫什麼
  Confern.exe convert 照片.jpg --to png     # 輸出在來源檔旁邊
  Confern.exe convert *.png --to jpg -o D:\out
  Confern.exe watch C:\收圖 --to jpg        # 盯著資料夾，丟進去就自動轉（Ctrl+C 停）
  Confern.exe watch --add C:\收圖 --to jpg -o D:\出圖   # 記進設定檔，下次啟動生效
  Confern.exe watch --list
  Confern.exe --strings-selftest           # 八語言字表自檢

  失敗碼：0 成功、9 至少一個檔沒轉成、4 命令本身打錯（會說錯在哪）。
  注意：Confern 是 GUI 子系統的程式，**在 cmd 裡用 > 重新導向會拿到空檔**
  （cmd 不等待這類程式）。要抓輸出請用 PowerShell 的 Start-Process 或管線。

去背（CUTOUT）
--------------
  內建 MODNet 模型（models\model_fp16.onnx，apache-2.0，授權全文就在同一個資料夾）。
  想要更乾淨的邊緣：把「可選-高品質去背模型\models\」裡的兩個檔複製到 models\，
  程式下次啟動就會優先用 BiRefNet；刪掉就退回原本的模型，CUTOUT 不會壞。

解除安裝
--------
  設定 → 應用程式 → 已安裝的應用程式 → Confern → 解除安裝。
  解除時會問要不要一併刪掉 %LOCALAPPDATA%\Confern（設定與日誌）——那是你的資料，預設保留。
  免安裝版：直接刪掉資料夾。

幾件實話
--------
  ．exe **沒有數位簽章**，第一次啟動 SmartScreen 會擋一下：點「其他資訊」→「仍要執行」。
    它不對外連線（只有你按去背且模型缺失時才會去下載）、不裝服務，
    唯一會寫登錄檔的地方是「開機自動啟動」，而且設定頁關掉就會移除。
  ．需要 Windows 10/11 x64 ＋ .NET 8 桌面執行階段。
