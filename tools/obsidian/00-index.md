# Confern（Tangerine Converter 的 Windows 版）

把 macOS 的 **Tangerine** 檔案轉換器移植成 Windows 版。

> **產品名稱 2026-10-02 定案：Confern**（`con` ＋ `fern`）。原本的工作代號 `Sidecar` 已全面改名——
> exe、`%LOCALAPPDATA%\Confern\`、登錄檔機碼都用新名；名稱的唯一擁有者＝`src/Sidecar/ProductInfo.cs`。
> C# 命名空間與 `src/Sidecar` 目錄刻意保留歷史名稱（產品改名與程式碼重構不混在同一個 diff）。

> **目標**：拖著檔案、按一個鍵 → 格式輪盤在游標處出現 → 選了就轉，**輸出寫在原檔旁邊，原檔永不變動**。

| D5 | MVP 範圍 | **只做圖片**（JPG/PNG/BMP/TIFF/GIF/WebP）；影音、PDF、去背延後 |
| D6 | 發行與收費 | 暫緩，不阻塞實作 |
| D7 | HEIC | **僅輸入、不輸出**；不散布 HEVC 編解碼器，依賴系統的 HEIF 擴充 |
| D8 | 混合類別選取 | **拒絕**（不存在共同可用的操作集） |
| D9 | PDF → DOCX | **永久不做** |
| D10 | 設定頁技術 | **WPF**（規格 §9.1 原本就保留給設定頁）；輪盤與進度列維持原生 GDI+，不引入 WPF Dispatcher |
| D11 | 外觀凍結 | 方向 D（冷鋼／薄荷）；**光暈關閉**（`WheelDesign.GlowEnabled=false`，參數全保留、改 true 即還原）；扇形外緣 **7px 圓角** |
| D12 | 診斷記錄語意 | **關＝只寫必要事件（預設）；開＝再加上高頻 detail 行**。不是「關＝完全不寫日誌」 |

## ⚠️ 生死線（M0.5，實作前必須先過）

先證明 **alpha=1/255 的 layered 視窗仍能被 OLE 拖放命中**（桌面／資料夾／第二螢幕 **10/10**）。
通過 → 進入規格 §4 實作；**任一失敗 → 退回浮動接收目標（路線 C），並重新協商「任意位置放手」這個需求。**
