# 自己驗一次 —— Confern 操作單（2026-10-08）

這份是給**你本人**用的：每一步都寫「做什麼 → 應該看到什麼 → 不對時長什麼樣」，
你可以自己判斷有沒有過，不必相信我的轉述。

## 0. 先決定用哪一份 exe

| 用途 | 路徑 | 說明 |
| --- | --- | --- |
| **日常操作（建議）** | `src\Sidecar\bin\Release\net8.0-windows\Confern.exe` | 就是我最新的建置；**模型已經在旁邊**（`models\model_fp16.onnx` 實測存在 ✓） |
| 出貨形狀 | `%TEMP%\confern-ship\app\Confern.exe` | 與要傳給別人的整包一模一樣（24 檔、含模型與授權） |

⚠️ **動手前先關掉舊的 Confern**（系統匣圖示右鍵 → 結束，或）：

```powershell
Get-Process Confern -ErrorAction SilentlyContinue | Stop-Process -Force
```

原因：程式有**單一實例守衛**，舊的還活著時你啟的新 exe 會直接退出，你會以為「怎麼沒反應」。

## 1. 五分鐘：GUI 手動走一遍（最重要的一段）

1. **雙擊** `Confern.exe`。
   - 應該：**系統匣出現 Confern 圖示**，沒有錯誤視窗。
   - 不對時：彈出 .NET 版本錯誤 ⇒ 那是 runtime 問題，不是程式問題。

2. **拖一張圖檔到螢幕上**（先試直接拖；沒反應就**按住空白鍵**再拖）。
   - 應該：出現**格式輪盤**（ROTATE 那一圈是格式，例如 PNG／JPG／…）。
   - 輪盤上會**畫出目前的觸發鍵名稱**（預設 `space`）——這是程式自己在告訴你按哪個鍵。

3. **拖曳途中按住 Shift**。
   - 應該：切到**工具輪盤**，扇形標籤是 `ROTATE / CLEAN / COMPRESS / CROP / READ QR / CUTOUT`。
   - **PDF 進來時應該多一格 `MERGE PDF`**（圖片時不該有）。
   - 放開滑鼠 = 執行該工具。

4. **測資在這裡**（都是 commit 進 repo 的 fixture，安全可玩）：

| 想測 | 拖這個檔案 |
| --- | --- |
| 圖片基本 | `fixtures\rembg\real-512.png` |
| QR（應該讀得到） | `fixtures\qr\qr-small-in-scene-160.png` |
| QR（**不該**亂報） | `fixtures\qr\no-qr-512x384.png` |
| 合併 PDF（3 個一起拖） | `fixtures\pdf\fx-a.pdf`、`fx-b.pdf`、`fx-c.pdf` |
| 壞檔（應該優雅失敗） | `fixtures\pdf\fx-broken.pdf` |

5. **系統匣圖示右鍵** → 應該正好三項：**設定 / 暫停 / 結束**。
   進設定頁確認一下「觸發鍵」那一行顯示什麼（Space／Tab／CapsLock／Escape／Shift）。

## 2. 三分鐘：用數字驗 CUTOUT（這次改動的重點）

準備一張**高解析、有毛髮**的照片。我這邊留著一張實測用的狗毛照：

```
C:\Users\User\AppData\Local\Temp\rembg-hard\runA\input.jpg   (1920x1281)
```

在 PowerShell（把 `<EXE>` 換成上面第 0 節的路徑）：

```powershell
$exe = '<EXE>'
$src = 'C:\Users\User\AppData\Local\Temp\rembg-hard\runA\input.jpg'

# A. 預設（修邊開）
& $exe --remove-bg $src --log "$env:TEMP\a.log"
# B. 修邊關（對照組）
& $exe --remove-bg $src --remove-bg-refine off --log "$env:TEMP\b.log"
```

會產出兩個 PNG（在來源資料夾，檔名帶 (1)、(2)）。**先看圖**：把兩張都打開放大到毛髮邊緣。

- 應該看到：**預設那張邊緣較乾淨、階梯感少，而且細毛還在**。
- 「修邊後」如果變成**光滑的一坨、飛散的毛絲全被吃掉** ⇒ 那就是修過頭了，請告訴我。

想看數字（**注意：要餵「去背後的 PNG」，不是來源照片**——餵來源會得到 `band=0.0000` 這種看起來很權威但毫無意義的數字，我自己踩過）：

```powershell
& $exe --remove-bg-inspect '<剛剛產出的 PNG 路徑>'
```

`matte band=` 是「半透明過渡帶的比例」，`edge=` 是帶內的邊緣陡度。預期：預設那張 `band` **比 off 那張小**。

## 3. 三分鐘：合併 PDF ＋ **真的用滑鼠拖一次**

這條是**從來沒有真人做過**的手勢（過去都只有視窗自測在驗）。

1. 一次把 `fx-a.pdf`、`fx-b.pdf`、`fx-c.pdf` 拖進去 → 按住 Shift → 選 `MERGE PDF`。
2. 應該開出**排序視窗**（不是捲軸，是自製的上／下翻頁，會顯示「第 X-Y 列，共 N 列」）。
3. **用滑鼠真的把某一列上下拖動**換順序 → 按確認。
4. 檢查產出的 PDF：
   - 頁數 = 三個檔的頁數**相加**（fx-a 6 頁、其餘見 `fixtures\pdf\README.md`）。
   - 順序 = 你排的順序。
   - 按**取消**再試一次 ⇒ **不應該產生任何檔案**。

## 4. 兩分鐘：跑一次自動驗收（最有公信力的一條）

```powershell
$exe = '<EXE>'
$repo = 'C:\Users\User\Desktop\專案\tangerine-win'
& powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$repo\tools\verify-m3d.ps1" -Exe $exe -Section S18,S19,S20,S21,S22 -LogDir "$env:TEMP\mylogs"
& powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$repo\tools\verify-m3c.ps1" -Exe $exe -Section S17 -LogDir "$env:TEMP\mylogs"
& powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$repo\tools\verify-m1d.ps1" -Exe $exe -Work "$env:TEMP\mym1d"
```

**預期**（我今天實測的）：

```
checks=107 pass=107 fail=0 inconclusive=0 expected=107
checks=20  pass=20  fail=0 inconclusive=0 expected=20
checks=74  pass=74  fail=0 inconclusive=0 expected=74
```

⚠️ 三支**要依序跑**（每一支自己會先殺掉 Confern），不要同時跑。
⚠️ 跑的時候**不要同時操作 GUI**（會搶滑鼠／單一實例）。
