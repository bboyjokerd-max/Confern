## Goal

拖曳中**真的看到輪盤**、能用鍵盤或滑鼠選格式（**本切片尚不轉檔**）：

- 位置＝游標 `+(18, +18)` px，**自動翻邊**不超出該螢幕工作區
- 直徑 220 px（依 DPI 縮放）；選中扇區外擴 6 px
- 扇區＝**排除原格式後**的可輸出格式（2–7 個）
- 中心顯示 `原格式 → 目標格式`；選中項下方顯示輸出檔名（多檔顯示 `N 個檔案`）
- 鍵盤：`←→↑↓` 環狀切換、`Enter` 立即執行、`Esc` 取消、觸發鍵放開即收起
- 自繪鬼影（游標旁 32 px 半透明檔案卡）
- 混合選取 → 拒絕並提示；無可轉換目標 → 提示
- 首次顯示 **< 100 ms**（視窗預先建立，不在拖曳中建立）

## Architecture

**兩層視窗（M1a 已凍結，本切片不得改動）**：

| 層 | 職責 | 樣式 | 擁有者 |
|----|------|------|--------|
| 命中層 `HitLayer` | 接 OLE 拖放（`DragAcceptFiles` / `WM_DROPFILES`）、被拖放命中 | `WS_EX_LAYERED`(alpha=1/255) + `TOOLWINDOW` + `NOACTIVATE` + `TOPMOST`；**絕不設 `WS_EX_TRANSPARENT`** | `HitLayer`（M1a，唯一） |
| 視覺層 `VisualLayer` | 畫輪盤／鬼影／文字 | per-pixel alpha（`UpdateLayeredWindow`） + **必須有 `WS_EX_TRANSPARENT`** + `TOOLWINDOW` + `NOACTIVATE` + `TOPMOST` | 本切片新增（唯一） |

視覺層永遠在命中層**之上**；它靠 `WS_EX_TRANSPARENT` 讓拖放**穿透**到下面的命中層。
這是本切片最大的風險（原 R5），因此 T1 是**生死線 2**：先用證據確認穿透成立，才寫輪盤。

**繪製分工**：`WheelPresenter` 是唯一繪製者（規格 §9.1 已具名）；`VisualLayer` 只負責視窗與
`UpdateLayeredWindow` 的搬運，**不含任何輪盤幾何知識**。

## Tech Stack

- .NET 8 / `net8.0-windows` / `WinExe` / x64（沿用 M1a）
- **繪製＝原始 Win32 `UpdateLayeredWindow` + GDI+（`System.Drawing`）**
- **不得新增任何 NuGet 相依**：本機**沒有 NuGet 全域快取**（`%USERPROFILE%\.nuget\packages` 不存在），
  任何 `PackageReference` 都可能因離線還原失敗；`Microsoft.WindowsDesktop.App.Ref` 目標套件已在本機
  （`UseWindowsForms=true` 可離線解析，`tools/dragsim` 已在用）。

### Decision：渲染器（偏離規格 §9.1 的「WPF」字樣）

| 選項 | 評估 |
|------|------|
| (a) WPF（規格 §9.1 現文字） | WPF 需要自己的 `Dispatcher` 訊息幫浦，而本行程已有一個原始 Win32 `GetMessage` 迴圈；整合是**真實風險**。且為 220 px 輪盤引入 WPF 的啟動成本與記憶體，對 <100 ms／<80 MB 兩個預算都不利。**不採用** |
| (b) **原始 Win32 + `UpdateLayeredWindow` + GDI+** | per-pixel alpha 直接由 `UpdateLayeredWindow` 提供（GDI+ 會正確寫入 alpha，傳統 GDI 不會）；沿用既有訊息迴圈；零新相依；220 px 點陣圖繪製 < 5 ms。**採用** |
| (c) Direct2D / DirectWrite | 品質與效能最好，但 COM interop 面積大，本切片不需要。**延後**（若未來需要動畫或複雜效果再評估） |

**這是規格變更**：規格 §9.1 把 UI 行程標為「.NET 8 + WPF」。T6 必須回寫該處，並記錄為決策 D10。
WPF 仍保留給 **M1f 的設定頁**（那裡的表單才真的需要它）。

## Compatibility Boundary

1. **命中層契約不變**：`HitLayer` 不得為了畫圖而被修改成會自己收層、或加上繪製職責。
2. **收層唯一權威仍是 `ReleaseGuard`**；`Esc`／`Enter`／滑鼠點擊扇區都必須**經過** `ReleaseGuard`，不得直接 `Hide`。
3. **零侵入不變式**：未觸發時視覺層必須不可見（`IsWindowVisible=False`），且兩個圖層都不得搶焦點。
4. **不碰使用者檔案**（本切片根本不寫檔）。
5. 既有 CLI 與 `--assume-explorer-foreground` 等診斷旗標語意不變。

### 步驟 2：`VisualLayer.cs`（完整）

```csharp
using System.Drawing;
using System.Drawing.Imaging;

namespace Sidecar;

/// <summary>
/// 視覺層：per-pixel alpha 的唯一視窗。
/// 契約：**必須**有 WS_EX_TRANSPARENT（讓拖放穿透到下面的命中層）與 WS_EX_NOACTIVATE（不搶焦點）。
/// 本類別**不含任何輪盤知識**——只負責「把一張 ARGB 點陣圖貼到某個螢幕座標」。
/// </summary>
internal sealed class VisualLayer : IDisposable
{
    private const string ClassName = "SidecarVisualLayer";
    private readonly Evidence _evidence;
    private readonly IntPtr _hwnd;
    private bool _visible;
    private int _frame;

    public IntPtr Handle => _hwnd;
    public bool IsVisible => _visible;

    public VisualLayer(Evidence evidence)
    {
        _evidence = evidence;
        Native.WNDCLASSEX wc = Native.CreateDefaultClass(ClassName, OnMessage);
        Native.RegisterClassEx(ref wc);

        _hwnd = Native.CreateWindowExW(
            Native.WS_EX_LAYERED | Native.WS_EX_TRANSPARENT | Native.WS_EX_TOOLWINDOW |
            Native.WS_EX_NOACTIVATE | Native.WS_EX_TOPMOST,
            ClassName, "SidecarVisualLayer", Native.WS_POPUP,
            0, 0, 1, 1, IntPtr.Zero, IntPtr.Zero, Native.GetModuleHandleW(null), IntPtr.Zero);

        if (_hwnd == IntPtr.Zero)
            throw new InvalidOperationException($"visual layer creation failed: {Marshal.GetLastWin32Error()}");

        int ex = Native.GetWindowLongW(_hwnd, Native.GWL_EXSTYLE);
        if ((ex & Native.WS_EX_TRANSPARENT) == 0)
            throw new InvalidOperationException("visual layer is missing WS_EX_TRANSPARENT (drops would hit the visual layer)");
        if ((ex & Native.WS_EX_NOACTIVATE) == 0)
            throw new InvalidOperationException("visual layer is missing WS_EX_NOACTIVATE (it could steal focus)");

        _evidence.Line($"visual layer created hwnd=0x{_hwnd:X} exstyle=0x{ex:X8} " +
                       $"TRANSPARENT=set(required) NOACTIVATE=set(required)");
    }

    /// <summary>把 bitmap 貼到螢幕座標 (x,y)。bitmap 尺寸即視窗尺寸。</summary>
    public void Show(int x, int y, Bitmap bitmap)
    {
        IntPtr screenDc = Native.GetDC(IntPtr.Zero);
        IntPtr memDc = Native.CreateCompatibleDC(screenDc);
        IntPtr hBitmap = IntPtr.Zero, oldBitmap = IntPtr.Zero;
        try
        {
            BitmapData bd = bitmap.LockBits(new Rectangle(0, 0, bitmap.Width, bitmap.Height),
                ImageLockMode.ReadOnly, PixelFormat.Format32bppArgb);
            try
            {
                var bmi = new Native.BITMAPINFOHEADER
                {
                    biSize = Marshal.SizeOf<Native.BITMAPINFOHEADER>(),
                    biWidth = bitmap.Width, biHeight = -bitmap.Height,   // 負值＝由上而下
                    biPlanes = 1, biBitCount = 32, biCompression = (int)Native.BI_RGB
                };
                hBitmap = Native.CreateDIBSection(memDc, ref bmi, Native.DIB_RGB_COLORS, out IntPtr bits, IntPtr.Zero, 0);
                if (hBitmap == IntPtr.Zero) throw new InvalidOperationException("CreateDIBSection failed");

                // GDI+ 的 Stride 可能含 padding，逐列複製。
                // 注意：Marshal.Copy 沒有 IntPtr→IntPtr 的多載（T1 建置時實測 CS1503），必須經由中繼緩衝區。
                int rowBytes = bitmap.Width * 4;
                var rowBuffer = new byte[rowBytes];
                for (int row = 0; row < bitmap.Height; row++)
                {
                    Marshal.Copy(bd.Scan0 + row * bd.Stride, rowBuffer, 0, rowBytes);
                    Marshal.Copy(rowBuffer, 0, bits + row * rowBytes, rowBytes);
                }
            }
            finally { bitmap.UnlockBits(bd); }

            oldBitmap = Native.SelectObject(memDc, hBitmap);

            var dst = new Native.POINT { X = x, Y = y };
            var size = new Native.SIZE { cx = bitmap.Width, cy = bitmap.Height };
            var src = new Native.POINT { X = 0, Y = 0 };
            var blend = new Native.BLENDFUNCTION
            { BlendOp = Native.AC_SRC_OVER, BlendFlags = 0, SourceConstantAlpha = 255, AlphaFormat = Native.AC_SRC_ALPHA };

            Native.SetWindowPos(_hwnd, Native.HWND_TOPMOST, x, y, bitmap.Width, bitmap.Height,
                Native.SWP_NOACTIVATE | Native.SWP_SHOWWINDOW);
            if (!Native.UpdateLayeredWindow(_hwnd, screenDc, ref dst, ref size, memDc, ref src, 0, ref blend, Native.ULW_ALPHA))
                throw new InvalidOperationException($"UpdateLayeredWindow failed: {Marshal.GetLastWin32Error()}");
        }
        finally
        {
            if (oldBitmap != IntPtr.Zero) Native.SelectObject(memDc, oldBitmap);
            if (hBitmap != IntPtr.Zero) Native.DeleteObject(hBitmap);
            Native.DeleteDC(memDc);
            Native.ReleaseDC(IntPtr.Zero, screenDc);
        }
        _visible = true;
        _frame++;
    }

    public void Hide()
    {
        if (!_visible) return;
        Native.ShowWindow(_hwnd, Native.SW_HIDE);
        _visible = false;
    }

    private IntPtr OnMessage(IntPtr hwnd, uint msg, IntPtr w, IntPtr l)
    {
        if (msg == Native.WM_DESTROY) return IntPtr.Zero;
        return Native.DefWindowProcW(hwnd, msg, w, l);
    }

    public void Dispose()
    {
        Native.DestroyWindow(_hwnd);
        _evidence.Line($"visual layer disposed; frames={_frame}");
    }
}
```

## T2 — 輪盤幾何（純函式）

**Files**：新增 `src/Sidecar/Visual/WheelGeometry.cs`

**內容**（全部為純函式，無視窗、無繪製）：

```csharp
internal static class WheelGeometry
{
    public const int DiameterPx = 220;      // 規格 §4.3
    public const int OffsetPx = 18;         // 規格 §4.3：游標 +(18,+18)
    public const int SelectedExtraPx = 6;   // 選中扇區外擴

    /// 起點在正上方（-90°），順時針排列。
    public static double SectorStartDeg(int count) => -90.0;
    public static double SectorSweepDeg(int count) => 360.0 / count;

    /// 角度 → 扇區索引（環狀）。以畫面座標（y 向下）計算。
    public static int SectorAt(double dx, double dy, int count);

    /// 翻邊：輪盤左上角不超出 work 矩形。
    public static (int X, int Y) FlipEdge(int cursorX, int cursorY, int size, Native.RECT work);

    /// 是否落在輪盤內（半徑判定）。
    public static bool Contains(double dx, double dy, int size, int extra);
}
```

**關鍵算式**（`SectorAt`）：`angle = (atan2(dy, dx) * 180/π + 90 + 360) % 360`，索引 `= (int)(angle / sweep)`；
`FlipEdge`：`x = cursorX + 18`，若 `x + size > work.Right` 則 `x = cursorX - 18 - size`，再夾在 `[work.Left, work.Right - size]`。

**驗收**：`--wheel-geometry-selftest` 印出已知輸入→輸出對照（例如 `count=4, 正上方 → 0`、
`count=4, 正右方 → 1`、`count=4, 正下方 → 2`、`count=4, 正左方 → 3`、邊界角度 ±0.01°），
全數符合則 exit 0，否則 exit 5 並印出不符項。**這是 post-change regression，不是 strict RED。**

### T7（新增）— 拖放酬載接線：OLE `IDropTarget`

**為什麼必須有**：`A1` 要求「拖曳單張 JPG、按住觸發鍵 → 20/20 次輪盤出現」，
`§4.3` 要求中心顯示 `原格式 → 目標格式`、下方顯示輸出檔名。
這些都需要**拖曳進行中**的酬載，而 `DragAcceptFiles`／`WM_DROPFILES` 只在**放手當下**才給檔案清單。

**做法**：在命中層視窗上 `RegisterDragDrop` 實作最小 `IDropTarget`：
`DragEnter`（取 `CF_HDROP` → 檔案清單 → 交給 `IFormatCatalog`）／`DragOver`（回傳 `DROPEFFECT`）／
`DragLeave`／`Drop`（既有 `WM_DROPFILES` 路徑不變，兩者並存並交叉確認）。
**驗收**：真實拖曳時日誌出現 `DragEnter` 與正確檔案路徑；`原格式` 不再是佔位符；
`DragEnter` → 輪盤顯示 ≤ 100 ms。**這一段需要真實滑鼠**，執行前必須先問使用者。
