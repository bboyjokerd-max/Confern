# 互動原型（mockups）

這裡放「不是產品本身、但值得留著」的設計原型。全部是單一 HTML 檔，直接用瀏覽器開就能看。

| 檔案 | 是什麼 | 來源 |
|---|---|---|
| `confern-wheel-demo.html` | 輪盤的互動演示：幾何、配色、標籤都照產品的常數（`WheelDesign`）。用滑桿可看兩層輪盤的切換。 | 2026-11-03 做第二層輪盤截圖時畫的，原本放在桌面 `viz\` |

**這些檔案不參與建置、也不進安裝檔**——它們只是讓人（或下一個 agent）不必重建一次就能看懂視覺規則。
產品真正的視覺在 `src\Sidecar\Visual\`，改那裡才有用。
