## 這個目錄的邊界

- **不是**程式的一部分：`archive/` 不在任何 `.csproj`／`.sln` 裡（已確認方案引用 0 筆）。
- **不要**把還在用的東西搬進來。搬進來的前提是「它已經不參與建置，而且重建或追溯的路徑已經寫在上面」。
- 搬移時的規矩：先算整組檔案的 sha256 清單，搬完再算一次比對（這次三組分別是 25/25、24/24、3/3 完全一致）。
